# Перезапуск

Старый прототип сохранён отдельно в Purchase-Agent, коммит `13caea9`.
Новый репозиторий начинается с чистой истории.

## Перенесено

- `tests/fixtures/legacy/basic_profile_form.html` и `intent_form.html`: копии синтетических форм старого проекта.
- `extension/src/profile.ts`: адаптация модели Identity/Document в TypeScript.
- Требования: ввод документа только после разрешения, отсутствие значений в журналах, остановка перед отправкой.

Маппер написан заново: текущая демоформа использует явные группы участников и точные имена полей.
Распределение по порядку повторения каждого типа поля из старого проекта не перенесено.
Старые фикстуры сохранены как материал для будущих адаптеров; текущий адаптер их не заполняет.

## Оставлено в старом проекте

FastAPI, PostgreSQL, Alembic, серверные миссии/провайдеры, Docker, универсальный LLM-агент.
Секреты, реальные профили, базы, cookies, браузерные сессии и git-история не копировались.

## Архитектурные решения

Расширение исполняет только явное действие в активной вкладке (`activeTab`, `scripting`).
Нет доступа ко всем сайтам, фонового мониторинга или удалённого управления Chrome.
Для непрерывной работы при закрытом браузере впоследствии потребуется отдельный компонент.
