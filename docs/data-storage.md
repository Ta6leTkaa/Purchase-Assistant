# Локальные профили людей

## Использование

1. Соберите расширение (`npm ci && npm run build`) и загрузите `dist/extension` в Chrome.
2. Нажмите значок расширения → «Мои люди · добавить или изменить».
3. Создайте хранилище с уникальной парольной фразой от 12 символов. Подтвердите пароль.
4. Добавьте человека. Обязательны имя и фамилия; можно задать понятное название,
   отчество, дату рождения, email, телефон и до 10 документов.
5. Сохраните. В карточках номера документов замаскированы; в редакторе их можно показать.
6. Скачайте зашифрованную копию в разделе «Защита и резервная копия».

Типы документов: паспорт РФ, загранпаспорт, свидетельство о рождении. Номер вводится
вместе с серией, если она есть. Формат намеренно не ограничивается российскими цифрами:
приложение пока не проверяет подлинность документов или правила конкретного продавца.
Истёкшие документы можно сохранить, но выбрать для заполнения нельзя.

В окне расширения разблокируйте хранилище, отметьте участников и выберите документ.
При нескольких документах выбор обязателен. Данные подставляются по порядку списка.
Изменение участников или документа отменяет предыдущую проверку формы.
Для текущего стенда нужны два профиля с датами рождения и документами.
Поддержка реального checkout Большого театра ещё не добавлена.

## Где находятся данные

Один vault на профиль браузера, без регистрации в облачном сервисе.
`chrome.storage.local` содержит только объект `purchaseAssistantVault`:
версию, параметры выработки ключа, соль, IV, идентификатор редакции и шифротекст.
Имена, даты, контакты и документы находятся внутри шифротекста.
`storage.sync`, `localStorage`, cookies и серверы для профилей не используются.

Шифрование: Web Crypto AES-GCM-256, случайный 96-битный IV на каждую запись,
PBKDF2-HMAC-SHA256 с 600 000 итераций и случайной 128-битной солью.
Заголовок контейнера аутентифицируется как AAD. Ключ Web Crypto неэкспортируемый.
Пароль и ключ не записываются в Chrome storage, резервные копии или журнал.

Доступ к storage ограничен `TRUSTED_CONTEXTS`. Записи сериализуются Web Locks,
а проверка редакции останавливает сохранение устаревшего состояния другим окном.
При изменении vault в другой вкладке открытые интерфейсы блокируются.

## Блокировка

У каждого окна собственная разблокировка. Ключ и расшифрованные профили существуют
в памяти только во время этой сессии. При ручной блокировке, `pagehide` и пяти минутах
бездействия приложение освобождает ссылки и очищает формы, карточки и поля паролей.
Проверка времени при возвращении фокуса учитывает задержки фоновых таймеров.
Закрытие popup завершает его сессию; повторное открытие требует пароль.

JavaScript не гарантирует немедленное физическое стирание строк из памяти.
Шифрование защищает сохранённые данные, но не заражённую ОС/браузер или открытую
разблокированную вкладку. Значения, уже введённые в форму сайта, при блокировке
хранилища остаются в форме — их жизненным циклом управляет сайт.

## Резервные копии и пароль

Экспорт — зашифрованный JSON в том же версионированном формате, без пароля/ключа.
Импорт сначала проверяет размер (до 2 МБ), структуру, пароль, целостность и профили,
затем атомарно заменяет текущий список после явной отметки пользователя.
Неверный пароль/повреждённая копия не меняют существующие данные.
Валидную копию можно восстановить и поверх повреждённого локального vault.
Восстановление создаёт новый IV и редакцию; используется пароль импортированной копии.

При смене пароля нужны текущий пароль и два совпадающих новых значения.
Меняются соль и ключ, данные перешифровываются. Старые копии сохраняют старый пароль:
для их отзыва нужно самостоятельно удалить эти файлы. После смены скачайте новую копию.

Пароль восстановить нельзя. При его потере помогут только копия и её пароль.
Удаление расширения удаляет локальный vault; копию храните отдельно от пароля.
При загрузке распакованного расширения сохраняйте одну и ту же папку и обновляйте
через «Перезагрузить»: другая папка может получить другой ID и другое хранилище.

## Проверки

`npm test`: шифрование, CRUD, перезапуск, неправильный пароль, повреждение данных,
смена пароля, резервирование/восстановление, ошибки записи и гонки между окнами.
`npm run test:browser`: настоящий изолированный Chromium, интерфейс управления,
выбор документов в popup, маскирование, смена пароля, перезапуск, импорт и удаление.
Для обнаружения ID тест добавляет только в временную копию расширения служебный
service worker. В production-манифесте фонового процесса нет.
Все профили браузерных тестов вымышленные; тестовый профиль браузера удаляется.

Источники решений:
- Chrome storage: https://developer.chrome.com/docs/extensions/reference/api/storage
- Web Crypto deriveKey: https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/deriveKey
- PBKDF2 work factor: https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html

Система прошла описанные проверки, но отдельный внешний аудит безопасности не проводился.
