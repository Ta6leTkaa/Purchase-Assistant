# Purchase Assistant

Помощник для быстрой покупки дефицитных билетов. Первый целевой сервис — Большой театр.
Конкретный спектакль и дата, заранее подготовленные участники, быстрый выбор мест и оформление.
ЛЛМ не используем.

Сейчас работают **зашифрованное локальное хранилище людей**, управление документами,
резервные копии и заполнение локальной демоформы. Реальный checkout Большого театра
ещё не подключён.

## Установка

Нужен Node.js 22 или новее.

```sh
npm ci
npm test
```

1. Откройте `chrome://extensions`, включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение», выберите `dist/extension`.
3. Нажмите значок расширения → **Мои люди · добавить или изменить**.
4. Создайте хранилище с паролем от 12 символов и добавьте членов семьи.
5. Скачайте зашифрованную резервную копию. Сохраните пароль отдельно: восстановить его нельзя.

После изменения кода выполните `npm run build` и нажмите «Перезагрузить» у расширения.
Не удаляйте расширение для обновления: это удаляет его локальные данные.

## Что умеют профили

Добавление, редактирование и удаление людей; ФИО, необязательные дата рождения и контакты;
несколько документов с типом, номером и сроком действия. Номера в карточках замаскированы.
Смена пароля, зашифрованный экспорт/импорт, автоблокировка после 5 минут бездействия,
защита от перезаписи данных устаревшим окном. Данные остаются в профиле браузера.
Подробности и ограничения: [docs/data-storage.md](docs/data-storage.md).

## Проверка заполнения

```sh
npm run demo
```

Откройте http://127.0.0.1:4173/family.html. Для проверки используйте вымышленные
данные: создайте два профиля с датами рождения и документами. В popup разблокируйте
хранилище, выберите этих людей и нужные документы, нажмите «Проверить форму»,
разрешите ввод и нажмите «Заполнить». Заказ не отправляется.

Каждое открытие popup требует разблокировки. На сайте после заполнения значения
остаются даже после блокировки хранилища.

## Проверки

```sh
npm test
npx playwright install chromium
npm run test:browser
```

Модульные тесты проверяют шифрование, восстановление, конфликты записи, валидацию
и заполнение. Браузерный тест проверяет интерфейс в изолированном Chromium,
включая сохранность после его перезапуска. Все данные тестов синтетические.
