# Purchase Assistant

Помощник для быстрой покупки дефицитных билетов. Первый целевой сервис — Большой театр.
Конкретный спектакль и дата, заранее подготовленные участники, быстрый выбор мест и оформление.
ЛЛМ не используем.

Сейчас работают **зашифрованное локальное хранилище людей**, управление документами,
резервные копии и заполнение локальной демоформы. Реальный checkout Большого театра
ещё не подключён.

## Установка

Нужен Node.js 22 или новее.

```sh
npm ci
npm test
```

1. Откройте `chrome://extensions`, включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение», выберите `dist/extension`.
3. Нажмите значок расширения → **Мои люди · добавить или изменить**.
4. Создайте хранилище с паролем от 12 символов и добавьте членов семьи.
5. Скачайте зашифрованную резервную копию. Сохраните пароль отдельно: восстановить его нельзя.

После изменения кода выполните `npm run build` и нажмите «Перезагрузить» у расширения.
Не удаляйте расширение для обновления: это удаляет его локальные данные.

## Что умеют профили

Добавление, редактирование и удаление людей; ФИО, необязательные дата рождения и контакты;
несколько документов с типом, номером и сроком действия. Номера в карточках замаскированы.
Смена пароля, зашифрованный экспорт/импорт, автоблокировка после 5 минут бездействия,
защита от перезаписи данных устаревшим окном. Данные остаются в профиле браузера.
Подробности и ограничения: [docs/data-storage.md](docs/data-storage.md).

## Проверка заполнения

```sh
npm run demo
```

Откройте http://127.0.0.1:4173/family.html. Для проверки используйте вымышленные
данные: создайте два профиля с датами рождения и документами. В popup разблокируйте
хранилище, выберите этих людей и нужные документы, нажмите «Проверить форму»,
разрешите ввод и нажмите «Заполнить». Заказ не отправляется.

Каждое открытие popup требует разблокировки. На сайте после заполнения значения
остаются даже после блокировки хранилища.

## Проверки

```sh
npm test
npx playwright install chromium
npm run test:browser
```

Модульные тесты проверяют шифрование, восстановление, конфликты записи, валидацию
и заполнение. Браузерный тест проверяет интерфейс в изолированном Chromium,
включая сохранность после его перезапуска. Все данные тестов синтетические.

## Исследование формы Большого

Откройте официальный сайт в своей авторизованной вкладке, нажмите значок расширения,
раскройте «Проверка подключения к Большому» и нажмите «Проверить открытую страницу».
Результат можно просмотреть и скачать как JSON. Разблокировка профилей не требуется.
Проверка не вводит значения, не нажимает кнопки сайта и не создаёт заказ.

### Чтение подсказок при наведении

Для ручной диагностики раскройте «Ручная диагностика подсказок» и нажмите «Начать чтение подсказок».
Закройте popup (например, клавишей Escape) и наведите курсор на 2–3 места,
задерживаясь примерно на секунду до появления подсказки. Нажимать на места не нужно.
Затем откройте popup → «Показать собранные места» → «Скачать данные подсказок».

Сбор только ручной, на две минуты и до 100 наблюдений. Есть кнопка остановки;
смена вкладки останавливает сбор, смена адреса очищает наблюдения. Данные остаются
в памяти страницы и скачиваются только по отдельной команде. В хранилище профилей
они не записываются. При перезагрузке страницы сбор и результаты исчезают.
Сейчас поддерживаются SVG `rect.seat` и строгий формат подсказки с сектором,
рядом, местом, ценой в рублях и явным статусом. Непонятные или неоднозначные
подсказки пропускаются. Привязка — наблюдение после ручного наведения,
а не проверенный контракт сайта; для автоматической покупки она пока не используется.

## Автоматический поиск билетов

1. Откройте схему нужного показа Большого в своей авторизованной вкладке.
2. Нажмите значок расширения, задайте число билетов, бюджет, сектор и соседство.
3. Если подходят именные места, отметьте «Рассматривать места по паспорту».
4. Нажмите **«Найти билеты»** и дождитесь результатов в popup.

Вручную наводить курсор и подготавливать список мест не нужно. Расширение само
последовательно вызывает UI-события наведения у элементов SVG, читает подсказки
и подбирает до трёх наборов по условиям. Чтобы узнать доступные названия секторов
до подбора, можно нажать «Прочитать секторы автоматически».
Есть прогресс и «Остановить поиск». Действия на схеме или смена страницы останавливают обход.
Выбор мест, нажатие «Продолжить», бронирование и оплата пока не автоматизированы.

Время обхода зависит от количества доступных элементов и реакции страницы.
Лимит — 1 500 элементов и 30 секунд; неполный результат явно обозначается.
Сайт может не реагировать на программные события наведения. Тогда приложение
покажет ошибку незавершённого поиска, а не сообщение «билетов нет»; обход защиты
сайта не выполняется. Работа этого способа на живом сайте требует проверки.

Ручной сбор оставлен в разделе **«Ручная диагностика подсказок»** исключительно
для исследования. Основной поиск его не требует и не использует его список.
Подробности: [docs/seat-planning.md](docs/seat-planning.md).
