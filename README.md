# Purchase Assistant

Новая версия помощника для заполнения данных семьи при покупке билетов.
Текущий результат — каркас расширения Chrome Manifest V3 с проверяемым заполнением локальной демоформы.
Это прототип: реальные сайты и хранение настоящих паспортных данных ещё не поддерживаются.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm test
npm run demo
```

1. Откройте `chrome://extensions`, включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение» и выберите `dist/extension`.
3. Откройте http://127.0.0.1:4173/family.html.
4. Нажмите значок расширения, оставьте выбранными двух тестовых участников.
5. Нажмите «Проверить форму», разрешите ввод тестовых данных и нажмите «Заполнить».
6. Проверьте обе группы; форма не отправляется автоматически.

Список содержит только вымышленные демонстрационные профили. Номера документов намеренно невалидные.
После изменения кода выполните `npm run build` и перезагрузите расширение.
Безопасное хранилище и интерфейс добавления настоящих профилей — отдельный следующий этап.

## Проверки

`npm test` собирает TypeScript и проверяет распределение людей, отказ при неоднозначности,
сохранение чужих значений, событие ввода, отсутствие отправки и запрет других URL.
DOM-тесты выполняются в jsdom; они не заменяют ручную проверку установленного расширения в Chrome.

## Структура

- `extension/` — исходники и интерфейс расширения.
- `tests/fixtures/` — синтетическая форма семьи и две формы старого прототипа.
- `docs/product.md` — сценарий и порядок развития.
- `docs/migration.md` — что перенесено и почему.

Нет серверной части, внешних API, аналитики, запросов к ИИ и механизма покупки.
Лицензия на использование исходного кода пока не выбрана; публичность репозитория сама по себе не предоставляет открытую лицензию.
